# devices — 设备注册记录

防僵尸注册：同一设备只能注册一个账号。

## 路径
`devices/devices.json`

## 字段
```json
{
  "device_hash": "SHA-256匿名哈希（不可逆）",
  "uid": "绑定的用户ID",
  "first_seen": 1790000000000,
  "last_seen": 1790000000000,
  "reg_count": 1,
  "status": "normal",
  "note": ""
}
```

## 规则
1. device_hash 是设备信息的SHA-256哈希，**不可逆**，不存明文设备信息
2. 同一 device_hash 只能绑定一个 uid
3. 同一设备24小时内注册尝试超过3次标记为可疑
4. 重复注册返回错误码 4031
5. 数据保留：账号注销后保留90天用于风控，之后删除

## 隐私说明
- 只存不可逆哈希，无法反推设备型号/序列号
- 用途：防批量注册、防刷量
- 不用于追踪用户行为
